# Periodic Node/Edge Decomposition Design

**Date:** 2026-07-10
**Status:** Approved design
**Target package:** MOFBB

## Goal

Make node/edge decomposition chemically and geometrically honest for MOFs whose
metal-containing SingleNode components are one-dimensional periodic rods, while
preserving finite PORMAKE-compatible building blocks and exact atom-level
reconstruction metadata.

The change must fix both observed pathologies:

1. CPO-27-Ni must no longer emit singleton `OX3` organic nodes created by
   cutting covalent aryl-O bonds.
2. Periodic metal rods must no longer be serialized as ordinary finite XYZ
   fragments containing artificial long internal bonds and missing their
   continuation through the unit-cell boundary.

HKUST1, MOF5, and UiO-67 contain rank-zero finite metal components and must
retain their current decomposition.

## Root Cause

### Translation-blind metal components

`BondNetwork` stores a minimum-image Cartesian vector for each source atom
pair. Ordinary NetworkX connected components discard the corresponding cell
translation. Both CPO-27-Ni and Zn2-TTFB therefore appear to contain finite
metal components even though traversing an internal cycle changes the cell
image by one lattice vector along `c`.

The emitted fragments are not valid finite molecules:

- the Zn2-TTFB representative contains two internal bonds of approximately
  20.02 and 20.13 angstrom;
- CPO-27-Ni representatives likewise contain closure bonds inconsistent with
  the spanning-tree unwrapping;
- the topology and reconstruction map omit the translated continuation because
  same-fragment connections are skipped.

### Physical bonds confused with logical ports

CPO-27-Ni's raw organic fragment is `C6H2O2X6`. Three physical bonds connect it
to each of two neighboring rod repeats. The organic splitter counts all six
bonds independently. It recognizes the aryl ring as a branching core and then
classifies each pendant phenolate O as a separate three-port organic node
because that O has one C-O bond and two Ni-O bonds.

The six physical bonds are required for atom-level reconstruction, but they
represent only two logical linker endpoints. Physical connection sites and
logical ports must therefore be modeled separately.

## Chosen Representation

### Finite crystallographic rod repeats

A rank-one periodic metal component is opened into a finite repeat by cutting a
minimum set of internal source bonds such that:

- the residual owned-atom graph remains connected;
- every residual cycle has zero lattice translation;
- the number of cut source bonds is minimal;
- chemically covalent nonmetal bonds are avoided when a metal-metal or
  metal-donor cut gives an equivalent valid opening;
- the selected result is deterministic under atom reordering.

Each internal periodic cut creates two X caps on the same fragment, one at each
source endpoint. The corresponding topology record is a translated self-edge:
the two endpoint slot identifiers are equal, but their relative cell
translation is nonzero. Each self-edge contributes two to physical
coordination.

This representation deliberately preserves the smallest repeat justified by
pure lattice translation. It does not infer a smaller screw-related or
chemically guessed SBU. In particular, Zn2-TTFB remains a Zn6 crystallographic
rod repeat; Zn2 reduction is outside the default contract.

### Physical and logical connectivity

Physical connection sites remain one-to-one with cut source bonds. They drive:

- X atoms in XYZ files;
- exact reconstruction-map endpoints;
- physical topology edges;
- PORMAKE placement and bond fusion.

Logical ports group physical connection sites by the neighboring fragment slot
and translated image. They describe chemical/topological endpoints without
discarding multidentate coordination.

Every fragment summary gains:

```json
{
  "physical_cn": 6,
  "logical_cn": 2,
  "logical_kind": "edge",
  "logical_ports": [
    {"logical_port_id": 0, "x_indices": [10, 12, 13]},
    {"logical_port_id": 1, "x_indices": [11, 14, 15]}
  ]
}
```

`num_x`, `cn`, and existing X-site records retain their current physical
meaning for compatibility. A multi-X logical edge remains an `organic_node` in
the physical PORMAKE layout because PORMAKE classifies two-X blocks as edges
and three-or-more-X blocks as nodes. `logical_kind` exposes its chemical role
without misrepresenting the assembly graph.

No reduced one-X-per-logical-port XYZ is generated by default because such a
view cannot reproduce every coordination bond.

## Periodic Bond Model

Add a canonical image-aware source-bond record:

```python
@dataclass(frozen=True, order=True)
class PeriodicBond:
    i: int
    j: int
    shift: tuple[int, int, int]
```

`i < j`, and `shift` is the integer cell translation applied to atom `j` when
the bond is traversed from `i` to `j`. Reverse traversal negates the shift.

The integer shift is reconstructed from existing data:

```text
direct = position[j] - position[i]
shift_cart = BondNetwork.vector(i, j) - direct
shift = round(shift_cart @ inverse(cell))
```

The derived fractional value must be integral within `1e-6`. A shift along a
nonperiodic axis, a singular periodic cell, or a nonintegral shift raises a
descriptive `ValueError`.

Existing pair-only fields remain available. New shift-bearing JSON fields are
additive, so readers that use only `source_cut_bond` continue to work.

## Periodic Component Analysis

For every node-role component:

1. Traverse the induced periodic graph from the minimum atom index.
2. Assign each atom an integer image offset.
3. For a bond reaching an already assigned atom, calculate the residual cycle
   translation.
4. Normalize nonzero residuals up to sign and calculate their integer rank.

Rank zero follows the current finite-fragment path unchanged.

Rank one enters periodic opening.

Rank greater than one is not automatically cut. It raises a clear unsupported
periodic-SBU error containing the component formula, rank, and generators. A
two- or three-dimensional inorganic component needs a separate representation
rather than an arbitrary finite cut.

## Selecting the Periodic Cut Set

For a rank-one component, enumerate cut sets in increasing cardinality until a
valid set exists. A valid set leaves one connected, zero-holonomy residual
graph. Search is bounded by a configurable internal safety constant, not a
public option; exceeding the bound raises a diagnostic error rather than
choosing an unverified cut.

Candidates are ranked lexicographically by:

1. number of cut bonds;
2. bond-class penalty:
   - metal-metal contacts;
   - metal-O/N/S coordination bonds;
   - other bonds involving a metal;
   - nonmetal covalent bonds;
   - bonds to H;
3. compactness of the fully unwrapped residual fragment;
4. sorted local chemical signatures of cut endpoints;
5. an atom-order-independent labeled-graph signature.

The cut-set selector must not use raw atom indices as a chemical tie-breaker.
If top-ranked candidates remain chemically/geometrically inequivalent and no
canonical graph signature distinguishes them, decomposition raises an
ambiguity error listing the candidate bond classes and lengths.

The current CPO-27-Ni inferred graph includes a short Ni-Ni contact. The
periodic-opening code treats it as an input bond; it does not silently rewrite
the bonding model. The selected cut's element pair, bond type, length, and
translation are recorded in the summary so the metal-metal policy can be
audited separately.

Pure-translation reduction of an explicitly repeated supercell is desirable
but is not required in this change. The finite block is the repeat represented
by the supplied periodic cell. Screw-axis reduction, including a guessed Zn2
unit for Zn2-TTFB, is explicitly out of scope.

## Fragment Materialization

Fragment materialization accepts ordinary boundary cuts plus periodic internal
cuts.

For an ordinary cut, behavior is unchanged: the fragment owns one endpoint and
gets one X cap.

For a periodic internal cut:

- both source endpoints remain owned by the same fragment;
- the source bond is excluded from internal fragment bonds;
- one X cap is placed from endpoint `i` toward the translated image of `j`;
- one X cap is placed from endpoint `j` toward the reverse translated image of
  `i`;
- each X site stores the source pair, canonical shift, internal source index,
  external source index, and oriented external-image shift.

The residual internal graph is unwrapped only after periodic cuts are removed.
All retained source-bond lengths must agree with `BondNetwork.vector` within
numerical tolerance. This prevents another spanning-tree closure artifact from
being written.

## Topology and Reconstruction

The topology builder must retain same-slot connections when their translation
is nonzero. It emits a separate topology edge for every physical cut bond,
including parallel translated connections; physical bonds must not be
deduplicated by slot pair and translation.

The reconstruction map gains shift metadata on every edge endpoint and handles
two X sites from the same slot for a periodic self-edge. Validation requires:

- every physical cut has exactly two mapped X sites;
- every X site is used exactly once;
- self-edge endpoint translations are inverse;
- every fragment owns each selected source atom exactly once;
- residual fragment graphs are connected and zero-holonomy;
- no retained internal bond is distorted by periodic unwrapping.

Duplicate slot-pair warnings remain diagnostic. Valid translated parallel
edges are identified explicitly and are not reported as accidental duplicates.

## CPO-27 Organic Rule

During organic splitting, absorb a pendant coordinating heteroatom component
into its adjacent covalent organic core when all of the following hold:

- it contains no carbon and at least one O, N, or S;
- it has exactly one covalent boundary to one organic-node component;
- every other boundary bond is an original metal/organic cut;
- absorption does not merge two distinct organic core components.

This rule preserves phenolate O atoms with the dobdc-derived aromatic core but
does not absorb carbon paths such as Zn2-TTFB's phenylene edges. It also does
not merge a heteroatom bridge between two organic cores.

For CPO-27-Ni the expected organic result is nine intact
`C6H2O2X6` physical fragments, zero `OX3` fragments, and zero internal C-O
cuts. Each fragment has physical CN6 and logical CN2, with three physical sites
in each logical port.

## Expected Sample Behavior

### Unchanged rank-zero cases

- HKUST1: Cu2 carboxylate paddlewheel nodes and three-connected BTC cores.
- MOF5: six-connected Zn4O/carboxylate nodes and two-connected phenylene edges.
- UiO-67: twelve-connected Zr6 nodes and two-connected biphenyl edges.

Their formulas, instance counts, X counts, and reconstruction validation remain
unchanged.

### Zn2-TTFB

The supplied P1 cell contains two rank-one Zn-carboxylate rods. The minimum
zero-holonomy opening requires two internal cut bonds per rod. The expected
physical metal representative is `C12H12O30X16Zn6`; the six `C6S4X4` organic
nodes and twenty-four `C6H4X2` edges remain unchanged. Four translated
metal-node self-edges are added across the two rods, for 52 physical topology
connections in total.

### CPO-27-Ni

The supplied P1 cell contains six rank-one Ni-containing rods. The exact
physical metal CN depends on the validated minimum cut set for the inferred
bond graph and is asserted from the selected source bonds rather than
hard-coded from a chemical guess. The required stable outcomes are:

- no retained nonzero-holonomy internal cycle;
- no distorted internal bonds;
- no `OX3` fragment;
- nine intact `C6H2O2X6` physical organic blocks;
- logical CN2 for each such organic block;
- complete two-sided mapping of every metal-organic and periodic cut.

## Components and Responsibilities

### `src/mofbb/periodicity.py`

Owns image-aware graph behavior:

- `PeriodicBond` construction and shift validation;
- component offsets, cycle generators, and periodic rank;
- bounded minimum cut-set search and deterministic scoring;
- zero-holonomy and retained-bond geometry validation.

### `src/mofbb/models.py`

Adds shift metadata to X sites and topology/reconstruction records without
removing pair-only compatibility fields.

### `src/mofbb/fragments.py`

Supports two-sided capping of periodic internal cuts and unwraps only the
zero-holonomy residual graph.

### Decomposers

Both decomposers audit metal-node components before materialization so neither
workflow emits invalid periodic XYZ nodes. `NodeEdgePorDecomposer` additionally
applies the pendant-heteroatom organic rule and computes logical port groups.

### Results and topology

Result writers expose periodic generators, chosen internal cuts, physical and
logical coordination, translated self-edges, and the expanded reconstruction
validation.

## Error Handling

- Reject invalid periodic cells or nonintegral bond shifts.
- Reject rank-two or rank-three metal components with a targeted unsupported
  periodic-SBU message.
- Reject cut searches that exceed the safety bound.
- Reject residual disconnected or nonzero-holonomy fragments.
- Reject unresolved inequivalent minimum cut sets.
- Reject a logical-port group that mixes different neighboring slots or cell
  images.
- Preserve current errors for organic fragments with fewer than two physical
  sites unless they are retained bound-solvent accessory linkers.

## Testing Strategy

All production behavior is implemented test-first.

### Periodicity unit tests

Synthetic periodic graphs prove:

- integer bond shifts in both endpoint directions;
- rank-zero finite cycles remain unchanged;
- a rank-one chain is opened by the minimum valid cut set;
- parallel periodic bonds are retained separately;
- internal cuts create two inverse X sites on one fragment;
- a translated self-edge contributes degree two;
- rank greater than one and unresolved ambiguity fail clearly;
- retained internal geometry contains no long closure bonds.

### Organic splitter tests

Synthetic fragments prove:

- a pendant O with one organic-core bond and multiple metal cuts is absorbed;
- a carbon path between an organic core and a metal node remains an edge;
- a heteroatom connecting two organic cores is not absorbed;
- physical sites are grouped into logical ports by slot and image.

### Sample regressions

Run all five CIFs under `/nanolab/libo/mof_builder/test_decom` and assert the
expected behavior above. Every sample must retain complete source-atom
ownership, `all_edges_mapped: true`, and `all_x_sites_used_once: true`.

Run the complete repository suite after focused tests. Regenerate the manual
inspection outputs and update `VALIDATION_REPORT.md` with the corrected counts
and remaining representation limitations.

## Non-Goals

- Inferring a Zn2 SBU from a screw axis.
- Automatically reducing arbitrary P1 supercells to a hidden primitive cell.
- Supporting rank-two sheets or rank-three inorganic components as finite
  PORMAKE blocks.
- Collapsing several physical coordination bonds into one reconstructable X
  atom.
- Changing solvent-removal semantics or the existing SingleNode atom ownership
  rules.
- Replacing distance-based bonding with a full bond-order perception engine.
